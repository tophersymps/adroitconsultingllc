Data flow

  • P1 pop/hub stats: GET /api/progress/achievement (new, server) → deriveProgress → AchievementStats via a small useAchievement hook.
  • P1 outline/hub constellation: derived client-side from useProgressSummary.completedLessons + lesson slugs (pure buildConstellation in src/lib/sky.ts). No new endpoint.
  • P2 profile sky: server loader getProfileSky(userId) reads completion_events → ProfileSky → FullSkySection. Guest branch → LockedSkyTeaser.
  • Certificate: existing eligibility derive + append certificate event + render CertificateCelebration before the printable Certificate.

Risks

  • Streak correctness: the live-streak fix changes semantics at the lesson-complete beat; P1 counter must use the post-write value (fetch achievement after the lesson event resolves).
  • Certificate double-log: page re-renders; idempotency guard must cover the certificate event (lesson_slug null still deduped by user+course+event_type).
  • Write-site audit / no-forge: all three writes derive payload server-side; metadata never accepts client score/tier.
  • RLS regression: verify rows remain select-own/insert-own/update-delete-none after constraint re-add.
  • Hub perf: ConstellationPreview stays compact; one dev server across sub-tasks.

Acceptance criteria (for QA)

  1. event_type accepts quiz/exam/certificate after migration 010; existing rows unchanged.
  2. Quiz run appends quiz event + score; exam ≥72% appends exam event; certificate page appends exactly one certificate event.
  3. deriveProgress streakDays = 0 when last event not today/yesterday; live streak still counted; new test passes.
  4. deriveProgress returns rank + ladder; rank = highest reached band.
  5. P1: star pop + live streak on lesson complete; full constellation + Chronicle on outline; compact preview on hub.
  6. P2: /profile full sky for signed-in; locked-sky teaser for guest.
  7. P2: certificate page reveals celebration before printable certificate.
  8. RLS holds for all five event types.
  9. npm run build + npm test pass; contracts still tsc-clean.
