Lesson Audio Refinements — Smart Narration + TTS Timeout Scaling

📅 September 18, 2026 📋 Adroit.io — Learn / Atlas audio 👤 Brainiac (Web Architect) 📄 v1.0

1. Problem

The merged lesson-audio scaffolding (feat/lesson-audio) narrates lesson MDX using the same pure builder as articles. Two gaps:

  1. Smart narration. mdxToNarration reads every section, including hands-on Try It steps a listener cannot perform, the Related Requirements list, and the References citation block. It never hands off to the existing knowledge check.
  2. TTS timeout. scripts/build-audio.js hard-caps the Kokoro subprocess at a rigid 120s. Lessons reach ~5.7k words (measured max 5,713) and the engine is killed at exactly 120s.

2. Catalogue truth (verified across 240 lessons / 9 series)

Two structural families:

FamilySeriesCountLayout
A — Atlas / cert trailomni-studio-cert, salesforce-data-architect, salesforce-sharing-visibility-architect54Deep Dive → Worked example → Configuration Walkthrough → Exam Traps → Try It → What's Next → Related Requirements → References
B — consultant / architectagentic-ai, ai-at-work, hermes-consultant (+intermediate, +advanced), salesforce-architect186varied concept sections → Worked example → The pitfall(s) → Try It → What's Next

Key asymmetry: the sections to cut are a tiny closed set (Try It, Related Requirements, References); the sections to keep are hundreds of varied learning headings. So we invert — an interactive-heading allowlist, treating everything else as learning by default.

3. Design: smart narration

Extend the pure mdxToNarration with opt-in lesson mode so the article path is byte-for-byte unchanged. New NarrationOptions fields: lesson?, tryItBridge?, knowledgeCheckTransition?.

Heading (normalized)Action in lesson mode
try it / try it: <subtitle>Emit tryItBridge once, skip section body (incl. nested steps)
related requirementsSkip section body, emit nothing
referencesSkip section body, emit nothing
what's nextREAD normally (recap + preview)
anything elseREAD normally (learning content)

Closing transition (appended once as the final line, lesson only): “That's the lesson. When you're ready, return to the lesson page to complete the knowledge check and test what you've heard.” Draft for Chris; no em-dashes.

4. Design: TTS timeout scaling

Replace the rigid 120s with a length-scaled timeout from the narration word count:

ttsTimeoutMs(narration) = min( baseMs + words * perWordMs, ceilingMs )
baseMs = 30_000   (engine/model load + first-chunk)
perWordMs = 90    (~2-3x measured Kokoro realtime)
ceilingMs = 900_000 (15 min hard cap = hang protection retained)

5,713-word max lesson → ~9 min (well inside the 15-min ceiling and far past the 120s wall). A pathological 10k-word input caps at 15 min instead of failing outright.

5. Data flow

Lesson MDX → mdxToNarration(raw,{lesson:true})
  → learning prose (Try It → bridge; KC transition appended)
  → word count → ttsTimeoutMs → Kokoro execFileSync(timeout)
  → learn/<series>/<slug>/<voice>.mp3 + .timing.json
  → R2 (verify by re-read) + Supabase dual-write → src/data/lesson-audio.ts

Playback unchanged: authed GET /api/audio/[slug], fail-closed 401/404, members-only access gate. No public/signed URL.
