# Statement of Work (SOW) — Summary

---

## Project Objective

Design and deliver a premium enterprise consulting website that elevates Adroit Consulting's market positioning, communicates service authority, and increases qualified client inquiries.

---

## In-Scope Deliverables

1. **Website Strategy & Information Architecture**
   - Stakeholder discovery sessions
   - Sitemap, navigation model, and conversion path design

2. **UX Direction & Visual Design**
   - Wireframes for 5 core pages (desktop + mobile)
   - Visual design aligned to brand palette (Carmine, Navy, enterprise neutrals)
   - Responsive component system

3. **Content**
   - Starter copy for all 5 core pages (Home, Salesforce Consulting, Business Process Automation, Web Development, Contact)
   - Page metadata (titles, descriptions) for SEO

4. **Platform Implementation**
   - Build on approved technology stack (React/Next.js, WordPress, or Salesforce Experience Cloud)
   - Content population and CMS/authoring configuration
   - Contact form with field validation and submission workflow

5. **Integration**
   - CRM-ready lead routing pattern (Salesforce Web-to-Lead, API, or middleware)
   - Analytics tagging (Google Analytics 4 or equivalent)
   - Cookie consent instrumentation

6. **Quality Assurance**
   - Cross-browser and cross-device testing
   - Accessibility validation (WCAG 2.1 AA target)
   - Performance optimization (Core Web Vitals targets)

7. **Launch & Stabilization**
   - Production deployment and DNS configuration support
   - 2–4 weeks post-launch stabilization support (depending on contract tier)

---

## Final Deliverables

| Deliverable | Format |
|-------------|--------|
| Production-ready public website | Live URL |
| Admin/content publishing guidance | PDF or Markdown |
| Technical handoff documentation | PDF or Markdown |
| Post-launch support | Time-boxed support window |

---

## Assumptions

- Client provides review feedback within agreed SLA (2–3 business days per cycle).
- One primary stakeholder group handles all approvals; no multi-track sign-off chains.
- Legal and privacy policy copy is supplied or approved by client counsel.
- Existing brand assets (logo, photography) are available in production-quality formats.
- Third-party platform licenses (hosting, CMS, Salesforce) are procured by client or agreed upon before build begins.

---

## Out of Scope

The following items are excluded unless added via a formal change order:

- Multi-language or localization support
- Advanced personalization engine implementation
- Large-scale legacy content migration (>10 pages)
- Custom middleware or application development unrelated to site scope
- Ongoing managed marketing operations (content calendar, campaigns, social media)
- Photography, videography, or custom illustration production

---

## Acceptance Criteria

- [ ] Approved page content is implemented accurately on all 5 core pages.
- [ ] Site meets the agreed browser and device support matrix.
- [ ] Core Web Vitals performance thresholds are met (LCP < 2.5s, FID < 100ms, CLS < 0.1).
- [ ] Accessibility audit passes at WCAG 2.1 AA level with no critical violations.
- [ ] Contact form submits successfully and lead routing functions as specified.
- [ ] Analytics and consent instrumentation fires correctly on all pages.
- [ ] Final UAT checklist is signed off by the designated stakeholder group.

---

## Change Management

- Scope changes are evaluated for timeline and budget impact before approval.
- All change requests are documented and require written stakeholder sign-off.
- Changes received after UX/Content Sign-Off (M2) may extend the delivery timeline.
