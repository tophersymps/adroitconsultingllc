# Adroit Consulting — Logo Usage Guidelines

---

## Clear Space

Maintain minimum clear space equal to the height of the **"A"** in the ADROIT wordmark on all four sides of the logo. No other graphic elements, text, or page edges should intrude into this zone.

```
          ┌─────────────────────┐
          │                     │
          │    ▲ clear space    │
          │    │                │
          │  ┌─┴──────────┐    │
          │  │   [LOGO]   │    │
          │  └─┬──────────┘    │
          │    │                │
          │    ▼ clear space    │
          │                     │
          └─────────────────────┘
```

## Minimum Display Sizes

| Usage | Minimum Width |
|-------|---------------|
| Full lockup (icon + wordmark) | 120px |
| Icon-only mark | 32px |
| Print full lockup | 1 inch / 25mm |

---

## Approved Color Treatments

| Variant | Usage |
|---------|-------|
| **Full color** | Default on white or light neutral backgrounds |
| **Full color (dark bg)** | On navy (`#004D98`) or charcoal (`#1F2937`) backgrounds |
| **Monochrome navy** | When color printing is limited or on light tinted surfaces |
| **Monochrome white** | On dark backgrounds where full-color contrast is insufficient |

---

## Brand Accent Palette

These colors are approved for UI elements, backgrounds, and typography that appear **alongside** the logo. They must never be used to recolor the logo itself.

| Name | Hex | Usage |
|------|-----|-------|
| Deep Carmine | `#A50044` | Primary accent — CTAs, highlights, active states |
| Navy Blue | `#004D98` | Secondary accent — headers, navigation, trust elements |
| Neutral Charcoal | `#1F2937` | Body text, dark backgrounds |
| Light Gray | `#F5F7FA` | Page backgrounds, cards, subtle separators |
| White | `#FFFFFF` | Primary page background, reverse text |

---

## Prohibited Treatments

Do **not** apply any of the following to the logo mark:

- Stretching, skewing, or disproportionate scaling
- Recoloring with non-approved colors
- Rotating or tilting
- Adding drop shadows, glows, outlines, or other effects
- Placing on visually busy or low-contrast backgrounds
- Cropping any part of the mark or wordmark
- Recreating or approximating the logo in alternative fonts

## File Format Selection Guide

| Channel | Recommended Format |
|---------|--------------------|
| Website (header, footer, hero) | SVG |
| Website (favicon) | ICO / PNG |
| Social media profiles | PNG (400px or 800px) |
| Open Graph / link previews | PNG (1200×630) |
| Email signatures | PNG (320w or 640w retina) |
| Print collateral | EPS (CMYK) or high-res PNG (300 DPI) |
| Presentations (PowerPoint/Keynote) | PNG (512px or higher) |
