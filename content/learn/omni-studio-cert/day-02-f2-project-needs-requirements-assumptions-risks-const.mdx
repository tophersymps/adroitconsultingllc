# Project Needs: Requirements, Assumptions, Risks, Constraints

**Exam guide requirement:** Determine a project's needs by evaluating a customer's requirements, assumptions, risks, and constraints.

**Domain:** OmniStudio Fundamentals (18%)

## Deep Dive

- Separate functional requirements (what the flow must do: capture X, call Y, display Z) from non-functional ones (performance, security, usability, channel). The exam scenarios hide both. Read for the hidden constraint.
- Assumptions must be validated early: external system availability, authentication model (Named Credential vs OAuth), data volume, record access. An assumption that 'the API returns flat JSON' is a risk until checked.
- Risks: external API downtime, licensing gaps (no OmniStudio license for a channel), field-level security restrictions, org limits (callout timeouts, DML limits), sandbox-to-production differences.
- Constraints shape the solution: license tier (which channels/components are allowed), org edition, legacy Managed Package Runtime vs Standard Runtime, no Communities license (blocks Experience Cloud embedding), security policy (no raw SOQL where FLS matters).
- The decision output is fit-gap: declarative OmniStudio config where it fits, programmatic (Apex/LWC/Remote Action) where it doesn't. Scope control means delivering the requirement, not the ideal architecture.

## Configuration Walkthrough

1. Elicit: who, what, when, where, how. Capture functional + non-functional requirements.
2. Validate assumptions against the actual environment (auth, data shape, volumes, limits).
3. Rank risks by likelihood/impact; design mitigations (retry, fallback, cache, error states).
4. Check constraints (license, runtime, channels, security) before choosing components.
5. Produce the solution approach: declarative-first, code where gaps exist.

## Exam Traps

- **Trap:** Ignoring field-level security as a constraint. SOQL-backed cards leak fields to low-privilege users.
- **Trap:** Assuming sandbox equals production (data volumes, connected systems, licenses differ).
- **Trap:** Choosing a component that works on Lightning but the requirement says Experience Cloud without a license for it.

## Exam Tip

Exam scenarios are constraint puzzles. The 'best' answer always respects the stated constraint, even if a fancier option exists.
