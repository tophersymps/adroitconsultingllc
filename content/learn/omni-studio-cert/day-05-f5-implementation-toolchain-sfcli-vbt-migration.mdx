# Implementation Toolchain: SFCLI, VBT, Migration

**Exam guide requirement:** Describe the tools required to complete the end-to-end implementation process (SFCLI, VBT, Migration, etc.).

**Domain:** OmniStudio Fundamentals (18%)

## Deep Dive

- Salesforce CLI (SF CLI) with the OmniStudio plugin is the modern deployment path: `sf project deploy/retrieve` moves OmniStudio components as source-format metadata between orgs and version control.
- VBT (Vlocity Build Tool) is the legacy CLI for Vlocity/OmniStudio metadata: package-style commands (`vlocity pack`, `vlocity deploy`) still relevant in Managed Package Runtime orgs.
- Migration Tooling covers org-to-org movement of OmniStudio definitions and supporting data. Components as metadata, and the data those components process (use Data Mapper Load or Data Loader for records).
- Critical distinction: components = METADATA (CLI/source/package tooling); records = DATA (Data Loader, Data Mapper Load, migration tooling). Mixing these is a classic exam trap.
- End-to-end flow: develop in sandbox → retrieve/commit to version control → CI/CD deploy → validate in UAT → promote to production. Source tracking and scratch orgs make this repeatable.

## Configuration Walkthrough

1. Set up SF CLI + OmniStudio plugin and authenticate to the org.
2. Retrieve components as source (`sf project retrieve start`), commit to git.
3. Deploy with `sf project deploy start` through sandbox → UAT → prod.
4. For Managed Package orgs, use VBT pack/deploy commands for component bundles.

## Exam Traps

- **Trap:** Using Data Loader to move OmniStudio COMPONENTS. It moves records, not metadata. Components are metadata that belong in CLI/source tooling.
- **Trap:** Believing there is one CLI for everything. SFCLI (modern), VBT (legacy package), and migration tooling each have roles. Know which to use when.
- **Trap:** Skipping version control. The exam expects a lifecycle, not one-off pushes. Develop in sandbox, retrieve to VC, deploy through environments.

## Exam Tip

Metadata → SFCLI/VBT. Records → Data Loader / Data Mapper Load. Know which side your artifact lives on.
