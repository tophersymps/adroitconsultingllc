## Deep Dive

**OmniScripts are guided journeys built from elements.** Each element has a job. Steps are pages. Groups and Blocks are containers that organize elements and can repeat. Input elements (Text, Number, Date, Select, Checkbox, Radio, File, and more) capture data. Action elements do the work: Data Mapper Extract/Load, Remote Action, HTTP, Save, and Set Values.

**Every element has a NAME, and that name becomes a key in the OmniScript's data JSON.** Names must be unique and path-safe. Formulas, actions, and downstream systems all reference these names, so a bad name breaks everything that depends on it.

**Dynamic interactions are how the journey reacts to answers.** Formulas compute values from other elements. Set-values populates elements. Visibility conditions show or hide elements based on data. Navigation rules route between steps based on what a user answers.

**The JSON data structure is the contract.** The OmniScript's data object holds every element value, and actions read and write that JSON. Understanding the JSON is the key to formulas and to debugging. When something fails, the JSON is where you start looking.

**It is a drag-and-drop, no/low-code builder with built-in debug tools.** The front-end (UI) is separated from back-end functionality (actions), which lets the UI and logic evolve independently.

## Configuration Walkthrough

1. Create an OmniScript and add Steps for the journey.
2. Add Groups/Blocks to organize inputs.
3. Add Input elements. Name them uniquely, because they become JSON keys.
4. Add Action elements for data operations (Extract to pre-fill, Load/Save to persist).
5. Add formulas, visibility conditions, and navigation rules for dynamic behavior.

## Exam Traps

- Duplicate element names cause data corruption, because names are JSON keys.
- Using actions where a formula suffices (and vice versa).
- Ignoring the data JSON when debugging. The JSON explains most failures.

## Exam Tip

Element name equals JSON key. Everything else (formulas, actions, debugging) hangs off that JSON.
