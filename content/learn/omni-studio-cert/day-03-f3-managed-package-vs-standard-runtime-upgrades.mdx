# Managed Package vs Standard Runtime; Upgrades

**Exam guide requirement:** Explain Managed Package Runtime vs. Standard Runtime, Automatic Upgrades, and Manual Intervention Upgrade.

**Domain:** OmniStudio Fundamentals (18%)

## Deep Dive

- Managed Package Runtime is the legacy Vlocity delivery model: OmniStudio components ride inside a managed package. Upgrades come as new package versions; major upgrades can require manual intervention (review, re-publish, re-test) before the org is on the new version.
- Standard Runtime is the modern model: OmniStudio components are native platform metadata delivered with Salesforce releases. They deploy via source format (Salesforce CLI) and upgrade automatically with platform releases, with no package install and no manual upgrade steps.
- Automatic upgrades apply seamlessly when the platform updates; manual-intervention upgrades require human action (approve, re-publish changed components, validate customizations) before completion. This distinction is a favorite exam point.
- Runtime choice affects everything downstream: how you version (metadata in git vs package), deploy (sf project deploy vs package install), test, and what happens on release day.
- Migration between runtimes: re-deploy components as metadata, re-validate behaviors (JSON keys, action types), and verify data packs/dependencies. An org can run both during transition.

## Configuration Walkthrough

1. Identify runtime in an org: check installed packages (Vlocity/OmniStudio managed package) vs source-tracked metadata.
2. For Standard Runtime: enable source tracking, retrieve components via SF CLI, store in version control.
3. For upgrade planning: classify each upgrade as automatic or manual-intervention; schedule manual reviews.

## Exam Traps

- **Trap:** Saying Standard Runtime still ships as a managed package.
- **Trap:** Believing manual-intervention upgrades happen without human action.
- **Trap:** Mixing up 'upgrade' with 'deploy'. Upgrades come from the vendor/platform; deploys are your own moves.

## Exam Tip

One axis: native metadata + automatic upgrades = Standard; package delivery + manual steps = Managed Package Runtime.
