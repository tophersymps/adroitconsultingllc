## Deep Dive

**Two levels of appearance control.** Element-level styling applies inline CSS per element (colors, fonts, spacing, alignment). Theme-level styling applies a shared theme across components for consistent branding.

**Themes centralize look-and-feel.** Define CSS variables (colors, font stacks, radii) and component styles once. Cards and OmniScripts consume them. Changing a theme restyles everything that uses it, which keeps branding consistent without touching each card.

**Inline styling is the exception.** It overrides theme defaults for one-off tweaks. Use it sparingly, because scattering inline styles across elements drifts away from the theme and gets hard to maintain.

**Styling affects usability.** Contrast, touch targets, and responsive widths all matter. The exam rewards sensible, accessible styling choices over flashy ones.

**Precedence order.** Component-level inline styles beat theme-level styles. Both beat platform defaults.

## Configuration Walkthrough

1. Create or select a theme with your palette and fonts.
2. Apply the theme to the FlexCard.
3. Adjust element-level styles for one-off emphasis.
4. Verify on mobile and desktop widths.

## Exam Traps

- Inline-styling everything instead of using themes. It is inconsistent and unmaintainable.
- Ignoring contrast and readability in custom styles.
- Expecting theme changes to apply where the theme is not assigned.

## Practice Questions

**Q1.** How do you apply consistent branding across many FlexCards at once?

A. A shared theme applied to the cards<br/>
B. Inline styles on every element<br/>
C. A custom LWC<br/>
D. Platform Cache

<details>
  <summary>Show answer</summary>
  **Correct: A.** Themes centralize appearance; inline styles are per-element exceptions.
</details>

**Q2.** Which takes precedence when both exist?

A. Element-level inline styling<br/>
B. Theme styling<br/>
C. Platform defaults<br/>
D. Random

<details>
  <summary>Show answer</summary>
  **Correct: A.** Component or inline styles override theme defaults.
</details>

**Q3.** What is a benefit of themes over inline styling?

A. One change restyles all components using the theme<br/>
B. Faster page loads<br/>
C. No CSS needed<br/>
D. Better security

<details>
  <summary>Show answer</summary>
  **Correct: A.** Themes give centralized, consistent appearance with single-point changes.
</details>

## Exam Tip

Theme = global branding, inline = local exception. Prefer themes for consistency.
