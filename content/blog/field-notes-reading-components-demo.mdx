This page exists to exercise the four Field Notes reading components end to end:
`TLDR`, `KeyTakeaways`, `Callout` (three variants) and `Steps` / `Step`. It is a
`status: draft` file, so it never reaches the public listing, never gets
prerendered, and 404s on the public route. It is reachable only through the
gated preview surface.

<TLDR>

- Four reading components ship from the MDX components map.
- Styling is an additive unlayered `.fn-*` block, tokens only.
- A draft article is the visual-QA surface; it 404s publicly.

</TLDR>

The prose around each block is deliberate. A component that looks right against
a blank page can still read wrong once the surrounding article rhythm is in
place, so this demo keeps real paragraphs, real headings and real lists between
the boxes.

## A rule worth keeping

<Callout kind="rule">

Never join across the transaction boundary in this pattern. The join is the
cheapest way to make a migration look correct while the counts drift underneath
it.

</Callout>

The point of the box is that a rule is not a paragraph. It is a thing the reader
is meant to remember and apply, so it gets a label, an accent rule and a
different surface from the body copy around it.

## Something that bites

<Callout kind="warning">

Watch the retry budget when the downstream call is idempotent only by accident.
The second attempt through a half-committed path is where the duplicate rows
come from.

</Callout>

A warning is visually distinct from a rule without relying on colour alone: the
word "Warning" is on screen, and the accent moves from the red rule to the amber
tint, so the signal survives for a reader who cannot separate those two hues.

## Why it works

<Callout kind="proof">

The 3:1 contrast on the accent rule is measured, not eyeballed. The token pairs
were computed against both the light and the dark surfaces before the block
shipped.

</Callout>

Proof boxes borrow the same emerald family as the takeaways block. That is
intentional: both mark "confirmed", and re-theming either one is a class change
rather than a structural one.

## How to do it

<Steps>

<Step title="Drain the queue">

Stop accepting writes before the migration runs. The queue is the only place
work can appear from now on, and a drained queue is a frozen target.

</Step>

<Step title="Verify the count">

Compare source and target row counts before resuming. If they differ, the
migration did not preserve what it claimed to preserve, and the correct move is
to stop rather than to reconcile by hand.

</Step>

<Step title="Re-open the queue">

Only after the counts agree. Watch the first few minutes of traffic for retries
that arrived from a client that had already given up.

</Step>

</Steps>

Each step is a real list item, so the numbering is produced by the document
rather than painted on, and a screen reader announces three steps instead of
three paragraphs.

## What to check in review

The rest of this section is ordinary article body: an intro paragraph, a heading,
a bullet list and a closing paragraph. Nothing here is boxed, which is exactly
what makes it useful as a control. If this prose ever changes weight, spacing or
colour, the scoped CSS block is leaking past its own classes.

- Ordinary bullets still draw the site's red diamond marker.
- Ordinary paragraphs still use the article leading and margin.
- Ordinary headings still underline.

If a boxed list and this list render identically, the `.fn-*` block is not
applying. If they render in different fonts, something upstream changed the
prose layer.

<KeyTakeaways>

- Reading components live in the MDX renderer map, so writers need no imports.
- Styling is an additive unlayered block scoped to `.fn-*`, tokens only.
- TLDR and KeyTakeaways use different accent families on purpose.
- Steps are a real ordered list, so the numbering is in the document.

</KeyTakeaways>
