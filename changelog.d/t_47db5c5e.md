### Learn lesson IA and kind-aware exam naming: architecture (t_47db5c5e)

**What** - Adds the decision-ready blueprint for Chris's four Learn items: `deliverables/learn-ux-exam-naming/architecture.md` (component boundaries, data flow, ADR-301..310, test strategy, risks), `api-contracts.md` (the seams between parallel implementation cards), `cards.md` (18 ready-to-file cards scoped 30-45 min for kara and steel), and the client-facing report `docs/architecture-learn-ux-exam-naming.html`. No application code changes.

**Why** - Sources on a lesson are generated GFM footnotes inside a renderer shared by five surfaces, so "move citations below the knowledge check" needs a render-pipeline split, not a layout tweak. Probes proved a definitions-only document renders nothing, so the split is two filtered renders of the same document (measured +3-5 ms per lesson, one compile 5.1 ms vs two 7.9 ms). Milestone checks exist only in a separate section while nothing maps a lesson to its check at runtime; `group` in `series.json` is not read at runtime, is dropped in the R2-5 degraded path and is already wrong for `agentic-ai`, so exam naming needs an explicit required `examKind`. D-1 (lesson gating), D-2 and D-3 are deliberately not decided: the gate ships as one constant (`LESSON_GATE_MODE = "advisory"`) read by one resolver that takes the mode as a parameter, so either answer lands without rework.

**Verified** - Repo read at `93198b82`: 12 Learn series (not 11), 510 of 510 lessons carry footnote definitions, `getKnowledgeChecks` reads ranges from each check file's title, `CheckCardList` and `ExamCard` each issue the same `/api/progress/quiz/tiers` GET on one series page, no duration field in `exam.json` (105 hardcoded on four surfaces), no lesson-level gating anywhere. Two probes against the real MDX toolchain confirm the footnote section can be dropped from one render and kept in another with matching ids and back-references.

The check page's own pass pill reads `quiz_run` while the exam gate reads `quiz_attempt` - flagged for a separate card, not changed here.
