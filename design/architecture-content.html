        ▲                                  │  sortPosts (frozen)
        │  ?category=&sort= URL state      ▼
        └────────────────────────  FeaturedPost / PostCard render  ──► static HTML (SSG)

No API routes, no database, no client fetch. Sort/category state lives in the URL (?category=, ?sort=) so the listing is shareable; the design pass changes classNames only, never data flow.

Schema Changes

None. No database, no API schema, no new data types. All design deltas are presentation-layer (className / CSS token) changes. `src/data/*` and `content/` are read-only inputs.
