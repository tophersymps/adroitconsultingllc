Knowledge check as a node in the syllabus

One milestone row rendered inside the lesson list, between lesson 5 and lesson 6 — visible on first view with zero progress, in both states, at five viewports. It replaces the bottom “Milestone checks” section.

Surface: Operate / Monitor States: Available · Passed No locked state Row ≥ 44 px No h-scroll at 360

01 Between lesson 5 and lesson 6 — the required viewport set

Each frame is the real syllabus surface at its exact width and height, same component CSS, responsive by container query. Zero completed lessons: no ticks, no progress, no reveal — the node is simply there, state Available. Frames are cropped to the L5→L6 boundary so the node sits inside the first view.

02 Position in the whole list — lessons 1–7

Proof of order: the node sits between lesson 5 and lesson 6 and nowhere else. It is not above the list and not its own section at the bottom. The exam card that used to follow the checks stays at the page bottom — out of scope for this card, untouched.

03 The only two states

Available is the default for a learner with zero progress, for a learner mid-range, and for a guest. Passed · 87% is the same row with the milestone achieved: the diamond fills, the band turns emerald, the badge carries the score. Nothing else exists — no lock, no padlock, no “after lesson 5”, no disabled row.
