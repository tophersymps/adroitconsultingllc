02 Design Tokens (additive)

3 new aliases on top of the shipped semantic system. No new hue — draft = pending = the amber the site already uses for "Coming soon". Full file: design/discovery/design-tokens-draft-preview.css.

--signal-draft-bg

#FEF3C7 (dark: rgba(245,158,11,0.14))

Amber tint band for the preview strip + badge. Aliases the shipped --signal-warn-bg.

--signal-draft-text

#B45309 (dark: --accent-hover)

Badge/kicker text — AA on the tint. Aliases --color-amber-700.

--border-draft

#F59E0B (dark: rgba(245,158,11,0.45))

Dashed band border + badge border — the "provisional" signal. Aliases --color-amber.

03 Components

Four new small components (steel builds from these specs). Everything else is reuse.

DraftBadge · status pill
Draft Published
Tag-shaped mono pill (rounded-full, px-2.5 py-0.5). Draft = amber tint + dashed border + pulsing dot. Published = emerald (--signal-done-bg), used on index rows only, never on the preview strip.
PreviewStrip · props { title, status, backHref }
Full-width band above the article column (1120 gutter), NOT inside the 720px article. Kicker row (mono 11px, pulsing amber dot + DRAFT), title row (text-sm semibold), message ("Not yet published — this preview is only visible to you"), back link right-aligned. Not sticky (ReadingProgress owns the top edge). Light/dark via semantic tokens.
DraftLocked · props { state: signed-out | no-access, nextPath? }
Auth-gate card at HTTP 200 (not 404, not bare redirect). Reuses GuestCTA anatomy: navy lock glyph + mono red kicker + headline + body + CTA. Two copy tiers: signed-out → "Sign in to preview drafts" + /login?next=; no-access → BA copy "This content is not yet available" + mailto (no fake button). Server-side check is what blocks content.
DraftList · optional (if Chris approves §4 of the brief)
Single-column rows (no cards, no icons, no hover glow), max-w 820px. Row: title (→ /preview/<slug>), category Tag, status pill, mono date/updated. BLOG/LEARN mono kind chip per row. Header: mono kicker "DRAFTS · N PENDING" + h1. Empty state reuses EmptyState anatomy. Auth-gated like the preview; excluded from sitemap/robots.

07 Handoff to Steel

What steel builds from this design

  • → Add the 3 draft tokens (--signal-draft-bg, --signal-draft-text, --border-draft) to globals.css + html.dark
  • → DraftBadge — span role="status", amber dashed pill + pulsing dot / emerald pill
  • → PreviewStrip — region above the article in the /preview route; NEVER inside it (article screenshot must not show it); not sticky
  • → DraftLocked — section at 200 with lock glyph; real <a> to /login?next= or mailto; no fake buttons
  • → Suppress on preview: ShareBar, MarkAsRead/LessonComplete, quiz, GuestCTA, featured pill
  • → Keep on preview: Header, Footer, ReadingProgress, BackLink (target /blog or series unless /drafts ships)
  • → Optional §4: DraftList at /drafts, single combined queue with BLOG/LEARN chips, excluded from sitemap/robots
  • → Status filter in build-posts.js / build-learn.js (the only build-script change)
  • → Public site untouched — zero diff on blog/learn renderers, posts.ts, feed, sitemap, published content
