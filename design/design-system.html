Motion System + Progress Tracking + Interactive Quiz

"Alive, not animated." Three connected systems built on the direction brief (t_7e4e4898): a shared motion language, dual-layer progress signals (content vs user), and a focused Operate-surface quiz. Surfaces: Monitor (read state, progress bars), Operate (mark-read, filter, quiz), cross-cutting motion.

07 Motion System — Postures

Three speeds, one language. Micro/Standard are everywhere; Moment is earned — reserved for accomplishment (read check, lesson complete, quiz grade, score ring). All CSS-based, auto-covered by the existing prefers-reduced-motion block.

PostureDurationEasingUse
Micro120–150msease-outColor, underline draw, icon swap, button press (active:scale-[0.98])
Standard200–250msease-outCard hover lift, arrow slide, filter switch, checkbox fill
Moment400–550mscubic-bezier(0.34,1.56,0.64,1) springaccomplishment only check pop, lesson complete, quiz grade + explanation reveal, score ring fill

See mockup-motion-lab.html for a live comparison of all three postures on signature components.

Quiz Tiers + Gating + Certificate

"One quiz system, three registers of pressure." Built on the discovery brief (t_e9c5c72d): the lesson quiz is a friendly practice card, the knowledge check is a milestone with a pass badge, and the exam is a navy-timered, no-feedback gauntlet that resolves into a score-ring verdict. The certificate is the quiet, formal reward. Surfaces: Operate (quiz flows), Command/Operate (exam), Monitor (check list + locked state), Decide/Learn (guest CTA + certificate).
