Immersive Three.js Constellations

Every lesson ignites a star. Every course is a sky you chart.

Full-fidelity mockups for the two 3D surfaces that replace the flat star render: the on-course tracker (a course's lessons float as one real constellation in 3D, stars igniting as you learn) and the profile galaxy (every course its own constellation sector, blog reads scattering as free stars). 01 Design tokens — star temperature arc

Additive on the shipped semantic system (Fortress navy surface, ice accent, brand red chrome). The 3D decision is the star temperature arc: cool to fire under UnrealBloom. Every token ships an html.dark remap. Read directly off the additive design-tokens-3d.css.

Unlitcool pinprick · no bloom
Currentcyan pulse · bloom 0.35
Ignitedwarm gold · bloom 0.6
Completewhite-hot · bloom 0.9

A lit star is layered light, never a drawn stroke: white-hot round core → tinted mid-glow → soft bloom halo, with only a faint tapered diffraction glint on the brightest cores — the exact stack steel bakes into additive glow sprites. Unlit is a bare pinprick (spike + bloom suppressed), so lit stars read unmistakably as stars, not planets or line-glyphs.

Red is not a star color. Completed constellations finish white-hot (#FFF1D8), the brightest, most luminous state of the same warm arc. Kryptonian red (#C8102E) is reserved for brand chrome only (nav pill, streak stat, cert mark) and never appears on a star in the sky. This was corrected in execution from the earlier discovery draft, which had a red finish-line state.

04 State matrix

Every star + scene state designed, not just the happy path.

Unlit
locked / unborn pinprick · no bloom, no line
Current
"you are here" cyan pulse ring
Ignited
completed · warm gold layered bloom
Complete
white-hot finish · highest bloom
Article star
free-floating read · white, hover label
Loading
lazy canvas shimmer · reduced-motion static

Error / empty states fall back to the shipped 2D sky (same celestial tokens) with inline retry — the 3D canvas is a progressive enhancement behind a dynamic import, never a hard dependency of the page.

05 Responsive behavior

Desktop ≥1024 · tablet 560-900

  • On-course: 3D scene + 29-row syllabus beside it (2-col tracker grid)
  • Profile galaxy: full 7-sector 3D galaxy, 640px scene, minimap visible bottom-right
  • Scene height collapses 640 → 480 (≤900)
  • Stat strip 4-col → 2-col

Mobile ≤560

  • Tracker grid stacks to 1 col; scene above, syllabus below
  • Galaxy scene 420px; minimap hidden; hud-bottom stacks to a column
  • Stat strip → 1 col
  • Interactive stars: touch target ≥44px (hover states map to tap)
  • DPR capped dpr=[1,2], render loop throttled

06 Handoff notes for steel

Build these components

  • ConstellationCanvas — lazy-loaded r3f canvas, ssr:false
  • SeriesConstellation3D — on-course tracker scene (Orion)
  • IgnitedStar / StarPoints — layered light sprite stack
  • ProfileGalaxy3D — multi-sector galaxy + camera fly
  • SectorMinimap — DOM overlay, click-to-fly
  • StarTooltip — drei Html / DOM anchor on raycast hover
  • RankIllumination — rank → galaxy luminance (display)
  • LoadingSky — lazy-load shimmer fallback

Motion + constraints

  • Bloom: UnrealBloom strength 0.7, threshold 0.85, radius 0.5; only lit/current/complete bloom
  • Ignition sequence: lit stars surge on one-by-one in lesson order (~120ms stagger)
  • Camera: slow drift + pointer parallax; fly tween 600ms on-course, 800ms galaxy
  • Hover lift ×1.35; reduce motion → static lit state, no ignition/tween
  • Stars vary per star: color temp, size by magnitude, staggered twinkle phase
  • Data from completion_events + contracts-constellations.ts; do not rename
  • Course→constellation map authored in code, star count = lesson count
