Requirement 3 — OmniScript Element Fundamentals

Every OmniScript is a composition of elements on a canvas. This lesson covers the element palette, data binding, and how elements pass results to one another.

Elements are the building blocks

An OmniScript is a linear or branched flow of elements — steps, fields, actions, and display blocks — that run in sequence. Each element binds to an input through a JSONPath expression, transforms it, and writes a result that downstream elements can read. Understanding which element type fits which job is the core of OmniScript authoring.

Step elements group fields into a single user-facing screen. Action elements execute server-side calls, like DataRaptor Load or Turbo Extract. Display elements render text, images, or tables without collecting input. The element order on the canvas is the execution order — and branching lets you route users down different paths based on prior answers.
