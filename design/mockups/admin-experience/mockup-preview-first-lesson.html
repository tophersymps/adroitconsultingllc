Lesson 1: What an Agent Actually Is (LLMs vs Rules vs Workflows)

AC
Adroit ConsultingAugust 04, 2026 · 9 min read
LearnAIAgenticFoundations

The definitions that matter for the whole 90-lesson track: what separates a rules system, an LLM workflow, and a true agent, plus how to tell which one you’re actually building.

Three systems, one blurry line

Most teams reach for the word “agent” the moment an LLM is involved. That’s a mistake. A rules system makes decisions from a fixed decision tree — deterministic, explainable, and useless outside the cases you wrote down. An LLM workflow chains prompt-and-response calls in a fixed order you scripted at build time. A true agent decides which step to take next at runtime, based on what it observed so far.

The shortest honest test: if removing the model doesn’t change the control flow, it’s a workflow, not an agent.

The first lesson’s core idea

What makes an agent an agent is that the control loop is open at runtime. You, the implementer, define the tools, the guardrails, and the goal — but the sequence of calls is decided by the model against live observations. That one property drives every downstream choice about temperature, context, tool design, and cost.

Where the loop lives in your stack

The agent loop — perceive, reason, act, observe — is one while loop. Understanding where each stage touches your code versus the runtime’s is the difference between a prototype and a production system. This section walks the pseudocode that runs underneath every framework, and names the exact seams where your business logic belongs.

We then trace what happens when a tool returns an unexpected shape, when the context window fills mid-loop, and how to make the loop fail loudly instead of silently degrading. These are the patterns the rest of the track builds on.

By the end of this lesson you’ll be able to classify any system you meet — vendor tool, open-source framework, or your own homegrown pipeline — as rules, workflow, or agent, and defend the label with a concrete mechanism rather than vibes.
