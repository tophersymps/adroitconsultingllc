03 Mockup Gallery

Desktop captures. Each mockup is fully responsive (single-column card on mobile) with a dark-mode toggle and inline state toggles.

/forgot-password — email entry (left) and generic confirmation (right). Confirmation is enumeration-safe: same message regardless of whether the account exists. State swap is aria-live="polite".
/reset-password — new + confirm password with min-6 and match inline validation (left), success state (right, "Continue to blog" per ADR-PWR-2).
/reset-password?error=expired|invalid — link-expired state (amber warn signal), CTA "Request a new link" → /forgot-password. Rendered as role="alert".
/login (signin mode) — "Forgot password?" link right-aligned on the Password label row (left); unconfirmed-email error state with "Resend confirmation email" action (right, role="alert").

06 Handoff to Steel (t_e25638b3)

Build notes

  • → Reuse the existing LoginForm card / input / button / status styling — the AuthCard recipe above is what's already on /login. Lift the exact Tailwind classes from src/app/login/page.tsx.
  • → Forgot link: signin mode only. Put it in the Password <label> row as a real <Link href="/forgot-password"> (ADR-PWR-2: no ?next=).
  • → /forgot-password: same card; on submit swap to the confirmation state with aria-live="polite" on the wrapper. Generic copy regardless of account existence (enumeration-safe).
  • → /reset-password: read error query param. expired|invalid → warn state ("Request a new link" → /forgot-password), role="alert". Else auth-gated new+confirm form (min 6, inline mismatch), success state → router.push("/blog").
  • → Unconfirmed error: in login signin mode, render the friendly message as role="alert" + "Resend confirmation email" button → POST /api/auth/resend-confirmation.
  • → Both new pages get a server layout with buildMetadata → noindex. Remove the inline "Mock state" demo bars before shipping.
  • → All auth status regions: error → role="alert", success/info → role="status" / aria-live. Focus moves to the heading or first field on state change.
