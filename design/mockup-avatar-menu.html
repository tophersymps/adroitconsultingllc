Account corner — avatar menu

The avatar (initials from email, deterministic hue) replaces the raw email + "Sign out" text button in the header. Click the avatar to open the menu. Use the controls below to preview the states.

Keyboard & behaviour

↵ EnterOpen / activate a menu item
↓ / ↑Move focus between items
Home / EndJump to first / last item
EscClose menu, return focus to trigger
Click outside / TabCloses menu
FocusFirst item (Profile) on open; red focus ring via global :focus-visible
