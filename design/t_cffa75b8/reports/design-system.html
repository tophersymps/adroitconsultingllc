5 · Responsive Behavior

  • Desktop (≥1024): 2-col path grid; Tracks = 3 connected cards in a row with arrows.
  • Tablet (≤820): grids collapse to 1 col; outline two-column becomes single column (profile below syllabus).
  • Mobile (≤480): track rail collapses to a left-margin connector (cards stack 1→2→3, arrows rotate 90°); chips wrap; search full-width; touch targets ≥44px.

6 · Accessibility & Motion

  • All interactive elements have focus-visible red ring (--focus-ring), already global.
  • Filter chips use aria-pressed; cards remain server-rendered in DOM for SEO.
  • prefers-reduced-motion respected globally — no gratuitous animation in the seam.
  • Difficulty colors pass AA on their tinted backgrounds (darkened hues chosen for light mode).

8 · Slop Audit + Wow Factor

Slop score: 1/10 — only a mild echo of the feature-card grid in the Learning Paths grid, which is appropriate for an Explore result grid (not a marketing page). No tech gradient, no generic indigo, no accent rails, no unearned glass, no monument stats, no center stack, no icon toppers; type is the shipped Inter + JetBrains Mono.

Wow-factor: 5/6 — real imagery (gradient bands + constellation hero asset), depth (layered shadows, hover lift), typographic scale (oversized hub title + LEVEL N mono labels), craft (consistent radius/spacing system, hover states everywhere), and the signature connected-track-path composition. Motion is restrained by design (hierarchy, not a loading bar).
