01 Surface Commitments

Committed per screen before any tokens — the anti-slop root constraint.

/admin · primary

Operate

Course + user management is an operations console. Density, selection state, and decisive actions dominate — no hero, no decorative stat cards.

/learn · extends

Explore

Existing editorial catalog, extended with status/access-model chips + honest entitlement rows. Not re-laid-out.

gated lesson

Decide / Learn

Paywall sells the unlock with the course's real access options — peek, locked rows, no dead end.

audit log

Monitor (within Operate)

Read-only, dense, mono timestamps. A glanceable trail sub-surface inside the admin deck.

07 Handoff to Steel

🛠 Build from the mockups + tokens

  • → Add the tokens + html.dark remap from design-tokens-course-catalog-admin.css into src/app/globals.css.
  • → StatusBadge + AccessModelChip: one shared component family (catalog + admin). Map status→signal (pending/live/archived/granted), model→5 hues. Readable mono uppercase, ≤0.72rem.
  • → Catalog (/learn): overlay chips on existing PathCard/LessonCard; add the "You have access" / "Get access" entitlement row. Do NOT re-layout Explore.
  • → Paywall (/learn/[series]/[slug] not entitled): navy panel + red glow, free-preview peek, dimmed locked rows (opacity ~0.45 + lock icons + mono "Content locked"), and access options from the course's model — server-rendered, never a dead end.
  • → Admin shell: 248px navy sidebar (red left-ring active), 64px toolbar (title + primary action + search), dense 56px row tables with checkboxes + selected ring + inline chips.
  • → Actions: Launch (pending→live), Grant/Revoke (with grant note), bulk grant (one row per user), role change. All write admin_audit_log + visible "audit recorded" toast.
  • → Matrix + audit: user×course grid (source + grant date, mono); read-only dense audit log.
  • → Move per the architecture (child t_22b26cb9) contract: DB is source of truth for status+entitlements; access seam server-side; blog stays public.
  • → Match motion discipline: hovers 150ms (rows) / 300ms (cards), toast 3s, live/granted dot pulse, reduced-motion + focus-visible red ring respected.
