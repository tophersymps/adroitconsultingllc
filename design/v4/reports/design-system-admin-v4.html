02 Additive Tokens

These ADD to the existing --signal-*, --am-*, --admin-* system in src/app/globals.css. Nothing is replaced. Every new token has an html.dark remap.

Banner surface

--admin-banner-bg · #060F1F

Deep-navy urgency panel with a red radial glow + red CTA. The dashboard’s single focal hero.

Analytics bar fill

--analytics-bar-fill

Navy→red gradient for high completion. Pure CSS — no chart library. Dark remap swaps to sky→red-light.

Admin menu accent

--admin-menu-icon · #C8102E

Red shield glyph + faint red tint for the privileged avatar-menu entry. Reads distinct from neutral items.

Launch signals

--admin-launch-ok · emerald / warn · amber

Ready-state green vs blocked amber on the readiness checklist. Destructive confirm reuses red-dark.

Full spec + utility classes (.admin-banner, .analytics-bar > i, .admin-menu-item .shield, .launch-check) in design/v4/design-tokens-admin-v4.css.

03 Screens — Light & Dark

Each mockup renders in light and dark. Captured via headless Chromium at 1360×900.

1 · Dashboard landing (light) — pending-launch banner (navy + red glow, pulsing dot, Launch CTA), 6-stat grid, recent-admin-activity feed + entitlements-per-course split.
1 · Dashboard landing (dark) — cards flip to #111827, banner stays navy, contrast holds.
2 · Completion analytics (light) — 3-card summary strip, inline-SVG sparkline (red), completion table with pure-CSS bars + signal pills.
2 · Completion analytics (dark) — bar fill remaps to sky→red-light gradient; no-enrollment bar stays gray.
3 · Admin dropdown entry (light) — shield icon + red Admin tag + faint red tint, placed after Settings. Gated to admins only.
4 · Launch preview (light) — Step 1 review dialog: amber “pending” strip on the lesson preview, readiness checklist with a blocking warn row.
