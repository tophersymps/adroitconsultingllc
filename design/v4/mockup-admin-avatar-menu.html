Admin dropdown entry — placement & gating

The Admin console item sits directly after Settings and before the theme divider, in the same roving-focus menuitem group. It is the only admin-only item.

Icon: a filled shield (privilege mark) in brand red. Treated as a privileged entry — faint red tint background (--admin-menu-tint) + a red Admin tag, so it reads distinct from the neutral account items. Hover brightens the tint; keyboard stays roving-focus.

Gating: render ONLY when the signed-in user is admin (server payload exposes isAdmin derived from user_roles). No top-nav link — this is the single entry point to /admin.

Toggle to "Member" to confirm the item disappears for non-admins.
